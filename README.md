# kubernetes-game-servers
Goal of this project is to containerize and deploy containerized dedicated game servers into my kubernetes cluster while a continue to learn kubernetes. Mostly because its fun. I've also set a hard requirement to not use any Ai for any of these servers (out side of maybe proof reading README.md files, if I care at the time that is) because using my brain is fun. Basically Ai is very boring to someone who loves the actual learning process more then the end product.
